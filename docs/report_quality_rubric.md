# Report Quality Rubric

A report is acceptable only if:

- Every key claim references evidence, factor, metric, backtest, or decision ids.
- It includes counter evidence and at least two alternative hypotheses.
- It separates blind market scan from portfolio overlay.
- It marks missing data explicitly.
- It returns `insufficient_evidence` when verified evidence is absent.
- It never cites raw article text that bypassed canonical evidence processing.
